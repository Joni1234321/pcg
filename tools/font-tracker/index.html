Bake letter-spacing into a .ttf by shifting every glyph's hmtx advance width. SDL_ttf has no tracking API, so the font file carries the spacing instead — FreeType reads the new advances and TTF_Text, TTF_GetTextSize and wrapping all keep working unchanged.

Lossless alternative

opentype.js rebuilds the font from its parsed model, so tables it doesn't round-trip (GPOS/GSUB, hinting) can be dropped. Use this page to find the value you like by eye, then produce the shipping asset with fontTools, which patches hmtx in place and leaves every other table byte-identical: 

pip install fonttools

python -c "
from fontTools.ttLib import TTFont
f = TTFont('font.ttf')
delta = round(-20 / 1000 * f['head'].unitsPerEm)   # <- the value from this page
hmtx = f['hmtx']
for n in f.getGlyphOrder():
    aw, lsb = hmtx[n]
    if aw: hmtx[n] = (max(0, aw + delta), lsb)
f['hhea'].advanceWidthMax = max(hmtx[n][0] for n in f.getGlyphOrder())
f.save('font-tight.ttf')
"

Zero-advance glyphs (combining marks) are skipped in both paths — widening them would detach accents from their base letters.
