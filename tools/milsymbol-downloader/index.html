milsymbol downloader

Render NATO APP-6 / MIL-STD-2525 symbols and export them as SVG, PNG or JPG.

1. Symbol codes (SIDC)

One code per line. 15-char (2525C) or 20-char (2525D / APP-6D) SIDCs are supported by milsymbol.

2. Output options

3. Preview

4. Download

Single file downloads directly. Multiple files download as a .zip.

Uses milsymbol by Måns Beckman (MIT) and JSZip (MIT).
