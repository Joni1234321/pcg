silhouette finder

Search realistic military silhouettes (weapons, vehicles, aircraft, ships) from Wikimedia Commons, recolor and export as SVG / PNG / JPG. Free, no API key. Quality varies — preview before adding.

1. Search

Results are SVG files only, filtered to keep things recolorable. Click a tile to add it to Selected.

2. Output options

Recoloring replaces every solid fill/stroke in the SVG. Works perfectly on flat silhouettes; complex multi-color SVGs may look odd — check Keep original for those.

3. Selected silhouettes

Multiple files always download as a zip including ATTRIBUTION.txt with the author / license info from Wikimedia Commons — keep this with your assets to comply with CC-BY.

Files come from Wikimedia Commons. Each file has its own license — read the tooltip on each tile and the generated ATTRIBUTION.txt. Many are public domain; many require attribution (CC-BY / CC-BY-SA).
